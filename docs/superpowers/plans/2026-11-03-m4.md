# M4：升级状态机与提醒、警告、遮罩

基线：M3 已同步公开提交 `3a299f271a3db438a2bc0335c0471756c36a18d4`，112 项测试通过。用户已授权连续推进，不再重复请求开工确认。当前分支 codex/m4；使用 executing-plans，最后一次独立审查。

## 行为

- 标准模式 10/40/90 秒；温和按 1.5 倍、严格按 0.5 倍。所有值在 defaults.json。
- 有可信分心结论才升级；unknown/uncertain/fallback 不升级。系统窗口/手动暂停/空闲暂停累计。
- 连续专注 20 秒清零当前等级；分心累计保留。切换两个分心窗口不会重置。
- 同一个可信辅助窗口达到策略上限，超出部分计入分心，从 L1 起步。换辅助对象重置该辅助连续时间。
- 30 分钟内实际分心超过 5 分钟，下一轮直接 L2；虚拟起步时间不计入统计。
- Core 直接消费 ActivitySegment 增量（包含当前片段快照），按 ID 去重，沿用已有精确空闲拆分和单调时间；IClock 负责遮罩最短显示时间。
- L1 右下角、L2 顶部横幅/所有显示器 4px 边框/提示音、L3 所有显示器遮罩；非遮罩提示不抢焦点，边框穿透鼠标。
- 遮罩 60 秒内不能普通关闭；“回到学习”始终可用。优先恢复最近学习窗口，无可用窗口则回主界面，用户可结束/暂停。
- 系统窗口和主界面优先可用；遮罩自身获得焦点时保持显示。系统窗口出现时隐藏干预界面。拦截前重新读取 HWND/PID/进程/标题，保护名单始终优先。
- 不结束任何进程；只在 L3 尝试最小化已确认的分心窗口。申诉和应急通行在 M6 实现，M4 不放无效按钮。

## 验证边界

以合成片段和假时钟测升级，不通过操作用户实际分心软件来触发遮罩。Windows 显示器枚举可只读验证；真实多显示器/多 DPI 覆盖不具备环境时如实列为人工验收。UI 冒烟用 .artifacts 独立发布目录，避免工具退出后残留的文件锁污染最终包。
