# M2 手动验收

启动 `dist/StudyGuardian-M2/StudyGuardian.App.exe` 或根目录 `Start.cmd`。

1. 不填目标点“开始专注”，应在输入框下提示“请输入学习目标”，不开始采集。
2. 选择 25/50/90，再切到自定义输入 3；温和/标准/严格应可切换。输入 0 或非数字应阻止开始。
3. 允许组添加进程 `Notepad.exe`；辅助组添加标题正则 `辅助资料`；禁止组添加标题正则 `游戏视频`。点 `×` 能删除，重新添加后仍可使用。
4. 添加标题正则 `[`，应提示“正则表达式无效”。修改为有效表达式后可添加。
5. 开始会话，浮窗显示 `03:00`，主窗口最小化。切到记事本停留 5 秒后应变绿；未知应用为琥珀色“待判定”。
6. 在记事本打开自己创建的 `辅助资料.txt`，5 秒后应为琥珀色“辅助”；打开 `游戏视频.txt`，5 秒后应为红色“分心”。这些标题规则应覆盖宽泛的 Notepad 允许规则。
7. 拖动悬浮窗空白处；浮窗应跟随移动且保持置顶。点击暂停后计时冻结，继续后恢复。
8. 点 `↗` 返回主窗口。点“悬浮窗”可再次收起主窗口；点“结束会话”后停止计时并返回开始界面。
9. 切到资源管理器、任务管理器或本程序，应立即灰色暂停。锁屏/睡眠再恢复，不把这段时间扣进会话。
10. 普通学习窗口无输入超过 5 分钟后显示离开；前 5 分钟仍计时，恢复输入后继续。
11. 等待倒计时归零，应自动结束并保存；“活动记录”保留判定，重开程序后历史仍在。
12. 窗口缩小、长中文目标、多个规则标签、125%/150% 显示缩放下检查换行和按钮；开始按钮应始终位于底部。

专注率只包括已判定的有效时间；公式为 on_task / (on_task + supportive + distracted)。最初的防抖时间、unknown、neutral 和暂停不参与。

M2 没有 URL 采集，不用浏览器页面来人工验证 domain/url 命中；这些规则由自动测试验证，扩展阶段再接入实际 URL。

## 已执行的验证

- 核心/SQLite 自动测试 80 项通过（含 M1 的 35 项回归）；匹配、安全保护、规则优先级、正则超时、暂停重叠、空闲边界、精确到期结算和历史兼容已覆盖。
- 实际窗口验证：目标输入、自定义时长和严格度；标签添加/删除；无效正则提示；开始会话；用户手动切换记事本后，数据库实际写入 on_task/rule；3 分钟会话自动完成并返回开始界面。
- 桌面工具未获准操作记事本，悬浮窗也未作为独立窗口被工具列出。因此拖动/暂停按钮的实际交互、辅助/分心颜色及多 DPI 检查留作以上人工步骤；对应计时/判定逻辑已有自动测试。

测试运行数据仅在本地忽略目录内，不进入仓库。
