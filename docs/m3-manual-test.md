# M3 手动验收

启动根目录 `Start.cmd`。发布目录自带运行时；首次启动仍不采集。

1. 未设置密钥时填目标、点“生成规则”，应显示“请先设置 API Key”；仍可手动添加规则并开始会话。
2. 点齿轮：查看 AI 开关、API Key 状态、模型；已有密钥不回显。空模型不能保存。
3. 用自己的 API Key 保存后，输入“用 Notion 学习税法一第3章 增值税”，点“生成规则”；三组标签可增删，辅助上限可修改，点开始才采集。
4. 同一个无本地匹配窗口停留 5 秒后等待判定，活动记录应写 `source=llm`；切走再切回，同策略且缓存未到期时应为 `cache`。
5. 修改目标、规则或模型后开始新会话，不应复用旧策略缓存；切换窗口期间返回的旧 AI 结论不能套到新窗口。
6. 使用无效密钥或断网，停留普通窗口：应用不崩溃，显示“AI 暂不可用”，结果为 supportive/fallback；本地规则继续生效。
7. 关闭 AI 开关后只使用本地规则。清除密钥并保存、重开设置后显示“未设置”。
8. 结束/关闭正在判定的会话，程序应取消请求并保存；重开后没有幽灵请求或额外采集。

本阶段没有浏览器扩展，因此真实窗口 URL 仍为空；混合站点 URL 区分和缓存优先级由自动测试验证，M5 再连真实标签页。
