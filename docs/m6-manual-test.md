# M6 手动验收

自动验证：Release build 0 错误/警告，165 项 Core/AI/Data + 9 项 Windows + 11 项扩展测试通过。独立验收包已实测设置滚动、阈值错误提示与保存、合成报告统计/时间轴、休息/提前结束、应急次数及通行倒计时、结束自动报告。验收程序已关闭。

1. 双击 Start.cmd，保持未开始：不采集。设置全局允许 notepad.exe、禁止一个自建测试程序；保存并重开核对。
2. 开始会话，切到记事本至少 5 秒；点击休息，显示 05:00，学习剩余时间不减少。期间切换窗口不产生活动元数据，扩展 /status.monitoring 为 false；提前结束或到期恢复。
3. 应急通行 3→2，5 分钟内 supportive/override 且不升级；同一次通行不能重复扣次，使用完 3 次后按钮禁用。新会话恢复 3 次。
4. 自行在设置输入 API Key；对已判定分心对象申诉，写理由。明确通过后只允许对应对象 10 分钟，过期恢复防抖/判定；拒绝/断网不放行，关闭窗口取消请求。切换会话不接受旧申诉。
5. 遮罩锁定期间申诉/应急不可用；回到学习始终可用。解锁后相应按钮可用，放行后遮罩退出。浏览器可用后退重新进入原页面。
6. 结束会话打开报告；核对 focus/(focus+supportive+distracted)，暂停/未知不入分母。辅助超时只计超出部分；来回进入已批准窗口不会虚构新的清零事件。
7. 设置关闭发送标题或 URL，用受控 HTTP 测试确认字段为空；仅本地存储仍保持原活动记录。勿在日志或截图中展示密钥。

无真实 API Key，因此在线申诉/模型可用性待人工验收。真实扩展安装/跳转、浮窗拖动、全屏遮罩按钮和多屏多 DPI 尚未人工验证。独立测试目录的数据不在发布包和 Git 中。
