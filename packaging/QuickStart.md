# Study Guardian

Windows 10/11 x64。双击 StudyGuardian.App.exe 直接使用；或双击 Install.cmd 安装到当前用户的 Programs/StudyGuardian，并创建开始菜单快捷方式。无需管理员权限或另装 .NET。

1. 填目标、时长和规则，点开始专注。
2. 设置里按需输入自己的 OpenAI API Key。没有密钥也能用本地规则。
3. extension 目录可在 Chrome/Edge 开发者模式中“加载已解压的扩展”；再在配对页填写桌面设置中的端口和配对码。
4. 运行中可以暂停、休息、申诉、应急通行，结束后看报告。托盘可以打开主窗口或悬浮窗。
5. 严格退出、意外退出后重启、开机启动均默认关闭，设置中自行开启。正常退出/关机不触发重启，重启后需手动开始新会话。

数据在应用目录的 data；升级时先正常退出再运行新版 Install.cmd，会保留数据。移动便携目录前先关闭自启，移动后重新开启。卸载时先在设置关闭自启和守护，再正常退出，删除安装目录及开始菜单快捷方式；需要保留记录时先保留 data。

此包未代码签名。真实 API、扩展浏览器权限和多屏行为请按仓库手动验收文档检查。
