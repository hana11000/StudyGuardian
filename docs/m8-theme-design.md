# M8 第一步：静谧磨砂基础

本轮交付独立演示窗口：浅深主题、四种状态光、玻璃卡片和控件样式。正式学习程序继续使用原样式。

- 背景暖灰白/深黑，三团柔和光色缓慢漂移；卡片的半透明表面、高光边和 3% 颗粒保持可辨层次。
- 内容保持清晰，用黑白灰按钮、胶囊选择和大留白。色彩只出现在光和小圆点。
- 状态由演示窗口按钮选择：专注、提醒、拦截、休息。不会改变学习会话或触发干预。
- 浅色/深色和动态效果可以直接切换。隐藏或卸载控件时停掉动画；系统关闭客户端动画时也静止。
- 这一步展示的是应用内弥散背景与玻璃层叠。系统 Mica/Acrylic、正式浮窗交互及屏幕遮罩属于后续窗口改造。
- MiSans 原版随应用资源打包并附许可与来源；数字使用系统 Segoe UI Variable Display，缺少时退回 Segoe UI。

验收：控件可操作、键盘焦点可见；四种状态与浅深主题可切换；八张实际 WPF 渲染图用于视觉确认；构建和现有测试通过。
