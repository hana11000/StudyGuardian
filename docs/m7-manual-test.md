# M7 手动验收

自动验证：Release build 0 错误/警告；168 项 Core/AI/Data +15 项 Windows +11 项 Node 测试通过。守护使用独立合成进程：意外退出约0.66秒重启；正常退出仅1次启动；连续快速退出合计4次启动后停止。安装用项目内临时目录，验证升级保留data、拒绝无标识目录、越界、data别名和错误校验和。未启用真实自启或实际使用目录的守护。

独立GUI已实测三个桌面开关默认关闭，以及严格退出的取消、匹配文字、倒计时和确认退出（测试副本2秒，正式配置60秒）。重复退出的修复有不显示窗口的真实 WPF 回归测试。完整683文件发布包已用Windows PowerShell 5安装到项目内测试目录，未创建快捷方式；zip及所有文件摘要通过校验，无data。

1. 运行 Start.cmd，或解压 dist/StudyGuardian-M7.zip。首次启动不采集；设置里严格退出、意外退出后重启、开机启动均未勾选。
2. 在独立测试副本开启严格退出；关闭窗口后先取消，原程序继续可用。再关闭，输入画面短句，等60秒后退出。文字修改会重新等待。确认窗口期间从托盘再次点“退出”或“打开”，应保持同一确认流程且不异常退出。
3. 开启“意外退出后重启”，用测试会话验证意外结束后5秒内重开，数据库将上次会话标记中断，新窗口保持未采集。正常退出不重启。关闭该选项后不再守护。
4. 自愿开启开机启动后重新登录Windows，核对程序打开且不采集；再关闭，后续登录不再启动。实际关机/注销应跳过严格退出倒计时且不重启。
5. 托盘：打开主界面、显示浮窗、暂停/继续、休息、退出。浮窗“−”收起后可通过托盘找回。严格退出和暂停状态应一致。
6. 解压包后双击 Install.cmd，默认安装到当前用户 Programs/StudyGuardian。先正常退出再安装新版，原 data 内容保留。便携目录升级需自行复制 data；本项目旧版本目录保持原处。
7. 浏览器扩展按 extension/README.md 配对；自填 API Key 后验证在线策略、判定和申诉。关闭/卸载应用前可取消自启；移动便携目录前先关闭自启，移动后再开启。

真实 API 调用、Chrome/Edge 扩展安装与跳转、Windows 登录/关机、托盘菜单/浮窗交互、真实多屏多DPI仍列为人工验收边界。自包含包没有代码签名。所有开发验收数据仅存于忽略目录，不随源码或发布包分发。
