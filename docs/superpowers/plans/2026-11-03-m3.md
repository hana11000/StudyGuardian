## 接口与文件

- Core/AiContracts.cs：StudyPolicy、DecisionRequest、AiDecision、IStudyAi、IDecisionCache、AiOptions。
- Core/DecisionPipeline.cs：本地结果优先、按目标/规则/模型隔离的缓存、混合网站限制、失败降级及短暂退避。
- Core/StudySession.cs：带窗口访问版本的 DecisionTicket；只把异步结果用于同一次仍在前台的访问。暂停、切换、重启使旧结果失效。
- AI/OpenAiStudyClient.cs、Schemas.cs、项目文件：HttpClient Responses API，strict json_schema，store=false，3 秒总超时，验证返回内容。
- Data/SqliteDecisionCache.cs、schema.sql、SqliteActivityRepository.cs：缓存持久化、过期清理、向前兼容 M1/M2。
- Monitor/ProtectedSecretStore.cs：当前 Windows 用户 DPAPI 加密、原子替换密钥文件。
- App/AiSettingsStore.cs、SettingsWindow.xaml/.cs：API 启用开关、密钥输入/清除、模型；设置存 data，密钥单独加密。
- App/SessionController.cs、SessionSetupControl、RuleGroupControl、MainWindow、ConfigurationLoader：生成规则后在原标签区修改；异步判定不阻塞采集；错误短提示。
- config/defaults.json：模型、超时、缓存、信心阈值、输入/输出限制、浏览器及混合网站名单。
- tests：规则优先、缓存/过期/目标隔离、混合页面、退避、取消、过时回复、真实 SQLite、HTTP JSON 合同及拒答/超时/畸形响应。

## 实现约定

- 生成策略使用 goal_summary、可直接编辑的 typed rules、supportive_time_limit_minutes；人工修改后的规则作为最终策略，不保留不可见旧规则。
- 未配置密钥时仅本地规则；已启用 AI 而请求失败时 supportive/fallback，不得作为后续干预依据。uncertain 不拦截。
- 缓存包含策略指纹及模型；浏览器进程禁止 process 级缓存；混合站点禁止 domain 级缓存。URL 保留路径/查询，标题只折叠空白。
- 请求只投影目标、规则和必要的进程/标题/URL、最近判定与停留时长；不发送句柄、PID、截图或正文。
- 不实际调用付费 API；个人密钥等待用户在设置中录入。按官方文档实现并用假 HTTP 合同测试验证，不声称已完成真实在线验收。
