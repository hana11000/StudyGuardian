# 浏览器配对

支持 Chrome / Edge（Chromium 120 或以上）。

1. 启动桌面程序，打开设置，点击“复制配对码”。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，选中本目录。
3. 点击扩展图标，在配对页填桌面设置中的端口和配对码，点“连接”。
4. 回桌面程序开始专注。未开始或暂停时，扩展只请求连接/监控状态，不读取当前标签页。

仅当前前台普通窗口的 HTTP/HTTPS 标签可上报。无痕、系统页、文件页不采集；不注入内容脚本，不读取网页正文。默认端口来自根目录 `config/defaults.json`；修改后运行 `scripts/sync-extension-config.ps1` 并重新加载扩展。

配对码保存在扩展的本地独立存储中，不使用浏览器云同步。桌面“重置”会立刻使旧码失效。断开在扩展选项中操作；移除扩展使用浏览器扩展管理页。

本机程序关闭、端口被占用或配对失败时，扩展不会拦截。实际网页跳转前重新核对标签 ID、URL 和待导航网址。提醒显示扩展徽标；L3 跳转到扩展自己的拦截页，“回到学习”唤起桌面学习窗口或主界面。
