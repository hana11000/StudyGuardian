# M7.1：AI 判定与规则选择验收

运行根目录 `Start.cmd`，或 `dist/StudyGuardian-M7.1/StudyGuardian.App.exe`。

1. **连接**：设置 → API Key / 模型 → 测试连接。成功显示耗时；无效密钥、模型或超时显示短错误。测试不保存设置，关闭窗口会取消请求。
2. **目标直接开始**：启用 AI 并保存，填写目标，规则留空，开始专注。切到学习应用停留至少 5 秒，浮窗先倒计时，再显示判断中、结果或错误；无需先生成规则。
3. **切换与缓存**：停留不足 5 秒不发请求。切到另一窗口时旧请求取消，旧结果不能覆盖新窗口。重访相同内容命中缓存时，API 次数不增加。系统窗口暂停。
4. **失败恢复**：断网并停留在无规则/缓存的窗口。失败显示原因与重试倒计时；不会拦截。恢复网络后，继续停留，默认 30 秒后自动重试。AI 返回信息不足时显示“AI 信息不足”，原因可在悬浮窗底部提示上查看。
5. **选规则**：开始页或设置页的允许/辅助/禁止点 `+`，勾选已打开应用，支持搜索、多选、刷新。应用添加进程规则；浏览器添加精确标题规则。点“手动输入”仍可添加域名、网址、正则。刷新失败会清空旧选择，避免误加。
6. **网站**：浏览器扩展配对后 URL 才能参与判定；没有 URL 也可根据窗口标题判断。标题信息不足时返回待确认。选一个浏览器页面不会放行整个浏览器。

当前配置仍是 5 秒防抖、3 秒请求超时、30 秒失败重试间隔。连接不稳定时可能多次重试；超时、未知及信息不足都不拦截。

升级保留旧目录。安装版用新包 `Install.cmd` 升级；便携版需在两版都关闭后将旧 `data` 复制到新目录。发布 zip 内不含个人数据。
