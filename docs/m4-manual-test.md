# M4 手动验收

启动 `Start.cmd`；可先关闭 AI，用两份无敏感内容的记事本文件测试，标题分别包含“学习测试”和“分心测试”。给前者添加允许标题正则，后者添加禁止标题正则。

1. 标准模式开始；切到学习文件，5 秒后专注为绿色。切到分心文件，5 秒防抖后开始分心计时。
2. 连续分心 10 秒出现右下角提醒，不抢焦点；40 秒出现顶部横幅、每屏 4px 红色边框和提示音；90 秒出现遮罩，分心窗口被最小化。
3. 遮罩普通关闭在 60 秒内无效；任意时刻点“回到学习”应恢复学习窗口。学习窗口已关闭、已变成被拦截对象或不存在时，应回主界面，可暂停/结束。
4. 连续专注 20 秒后重新分心，应从宽限开始；30 分钟累计分心超过 5 分钟后，下一轮应直接警告。切换两个分心窗口不能刷新宽限。
5. 辅助上限设 1 分钟；同一可信辅助窗口超过上限开始提醒。未知、uncertain、fallback 即使长时间停留也不能触发干预。
6. 暂停、锁屏、任务管理器、设置或主界面出现时应隐藏干预；系统进程不得被最小化。恢复后统计不得将暂停时间算入。
7. 温和阈值为 15/60/135 秒，严格为 5/20/45 秒。浮窗的状态颜色随等级变化。
8. 使用多屏、负坐标副屏及不同缩放比例；检查全屏覆盖、边框物理宽度、所有遮罩上的返回按钮。插拔显示器后应重建覆盖。
9. 结束后查 SQLite events.level：警告为 2，拦截为 3；后续保存同一事件不能把 3 降回 0。

已执行：Release 构建 0 警告/0 错误，130 项 Core/AI/Data 和 4 项 Windows 测试通过。假时钟覆盖全部阈值、降级、加速、辅助超时、暂停、去重和返回目标保护。独立临时 UI 包以 1 秒防抖、2/4/6 秒升级和 10 秒锁定进行测试，真实窗口记录得到 on_task/rule 和 distracted/rule/level=3；测试程序均已退出。产品默认阈值未改。
