# Study Guardian M2 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 在已验收的 M1 上增加手动配置学习会话、本地规则判定和可暂停的悬浮窗。

**Architecture:** 保留 M1 的 Win32 采集与串行 SQLite 写入；Core 负责规则和基于 IClock 的会话统计，App 的 SessionController 协调采集、存储及两个界面。规则作为本次会话策略保存到已有 policy_json；使用已有 events.verdict/source，不新增数据库表。

**Tech Stack:** .NET 8 / WPF / Microsoft.Data.Sqlite；沿用 MSTest，不新增依赖。

**Spec:** 用户本轮的 M2 范围；AGENTS.md；docs/design.md。M1 已验收，M2 已确认，后续里程碑另行逐阶段实现。

## 已选行为（随清单一起确认）

1. 系统名单、自身 PID 和无法读取的窗口返回 neutral；保护规则优先于用户规则。
2. 匹配优先级：url > title_regex > domain > process；同一优先级为禁止 > 允许 > 辅助。特定页面规则可覆盖整个浏览器进程的规则。
3. process 忽略大小写和末尾 .exe；domain 匹配本域及真正子域；url 精确匹配规范化 HTTP(S) 地址，保留路径和查询，忽略片段；标题正则忽略大小写。
4. 普通窗口停留满 5 秒再判定，之前为 unknown；系统窗口立即 neutral。颜色：on_task 绿，supportive/unknown 琥珀，distracted 红；暂停/neutral 灰。
5. 倒计时在普通窗口上运行；手动暂停、系统窗口、离开、锁屏、睡眠不扣时。到零自动结束，剩余时间不为负。
6. 专注率 = on_task 时长 / (on_task + supportive + distracted 时长)。unknown、neutral、暂停不参与；无已判定时长显示“—”。首次 5 秒不追溯判定。
7. 目标简称由界面截断显示。严格度提供温和/标准/严格，保存选择；M2 不执行后续阶段的干预措施。
8. M2 尚无网址来源：domain/url 匹配与测试完整实现，实际采集 URL 为空时不命中这两类规则。
9. 规则命中与系统保护写 source=rule；无匹配/等待判定写 source=fallback。保留旧 M1 行的 verdict=NULL/source=monitor。
10. 悬浮窗置顶、半透明、可拖动，提供暂停/继续及返回主窗口；主窗口保留结束会话和活动记录入口。
