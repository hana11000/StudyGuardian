## 设计

- 使用框架自带 TcpListener，仅监听 127.0.0.1；严格限制 HTTP 路径、方法、Host、Origin、长度、并发和总超时，不增加依赖或 URLACL。每请求关闭连接，不实现通用 HTTP 服务器。
- 本机配对码随机生成并用 DPAPI 保存。设置显示端口、复制/重置配对码；扩展选项输入端口和配对码，保存在 storage.local，不同步。
- 原生前台进程、标题与扩展的 focused 标签报告共同校验；过期、乱序、后台或不匹配的报告不提供 URL。禁止猜测 URL，标题不符时按原有本地规则/AI 降级。
- 活动会话才接收元数据；未开始、暂停、系统暂停时不保存扩展活动。状态请求不带标签元数据。
- 本机保存有时效的精确标签拦截命令，避免 L3 最小化先于扩展轮询而漏跳转。扩展收到命令重新检查 tab ID、active、URL 和 pendingUrl，绝不把旧命令用于新页面。
- MV3 使用 tabs/windows 事件、30 秒 alarms 和运行中的短轮询；无 content script，不读取页面正文。worker 重启后从 storage.session 恢复实例和序号。
- blocked.html 不把原网址写入查询字符串，返回按钮回桌面学习界面。辅助/娱乐同站按具体 URL/标题已有规则与缓存判定。
- 扩展配置由根 defaults.json 生成，所有阈值在根配置管理。
