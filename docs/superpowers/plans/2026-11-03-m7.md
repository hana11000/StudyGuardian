基线 c6f0e1a418f1c136a5e3d492e17812931060ebaa，174 .NET +11 Node 测试。用户授权持续推进；逐项验证后一次独立最终审查。所有可选保护默认关闭，开发验收不修改真实自启设置。

## 方案与接口

- Core `DesktopOptions` 配置严格退出短句、等待60秒、刷新间隔、守护轮询250ms、重启延迟500ms、快速失败窗口60秒/最多3次；所有值来自 defaults。
- `ExitGate(IClock,options)` 输入完全匹配后启动等待，改动文字即取消等待；允许取消并返回程序，系统关机/注销跳过等待。
- `DesktopPreferences` 保存严格退出/守护两个布尔值（默认false）。自启以当前用户 Run 项真实状态为准，只有设置保存时发生实际变更，不在启动自动写注册表。
- `AutostartRegistration` 通过可替换存储隔离注册表；每安装目录拥有独立项名，启动命令正确引用绝对路径，取消只删除自己的匹配值。
- `WatchdogClient` 创建每代唯一的停止事件并启动隐藏 helper；正常关闭、关闭选项、系统退出立即发出停止信号。重启后的子进程继承事件而不重复启动 helper。
- `WatchdogSupervisor` 仅观察 PID+启动时间+完整路径全部一致的应用；程序意外终止后5秒内重开，不恢复采集。helper使用同目录目标固定文件名，不接受任意可执行文件。连续快速失败有上限；正常退出或关闭守护不重启。守护也可被任务管理器结束。
- 主窗口与托盘共用退出入口；托盘提供打开、浮窗、暂停/继续、休息、退出。浮窗可收起到托盘。使用系统框架 NotifyIcon，无新NuGet。
- 发布自包含 win-x64 包（app+watchdog子目录+扩展）；附 Install.cmd/Install.ps1，按用户目录安装，升级保留data。安装只复制清单文件，拒绝越界/数据文件/无标识的已有目录，默认创建开始菜单快捷方式，测试传项目路径且不创建快捷方式。
- 可移动包与安装包共用代码；生成zip和SHA256。不签名、不自动上传二进制；公开GitHub同步源码。最终包首次启动无采集、无守护、无自启。
