# M5 手动验收

使用 `Start.cmd` 和发布目录内的 `extension`。安装与配对见 [扩展说明](../extension/README.md)。

1. 先不开始会话，浏览普通网页。扩展网络请求只有状态查询；SQLite 不应新增会话/事件。
2. 配对页故意输入错误配对码应显示连接失败；输入正确码应显示已连接。桌面重置配对码后旧码应立即失效。
3. 关闭 AI，创建两条同域的精确 URL 规则：一个 B 站学习视频为辅助，一个游戏视频为禁止。开始会话，分别停留超过 5 秒；记录中 URL 与页面一致，verdict/source 分别 supportive/rule、distracted/rule。
4. 在两个标签页、多个窗口、Chrome/Edge 间切换。后台标签标题更新不能改变当前判定；新标签不能继承旧页结论。浏览器标题被第三方改写或超出采集限制时，URL 可为空，不应猜测。
5. 持续停留禁止页面到 L3，桌面遮罩和最小化后，原标签仍应跳转到 blocked.html。此时若已换成另一页面，旧命令不能把新页面跳走。
6. 拦截页“回到学习”应返回有效学习窗口，或回主界面。无学习窗口时不得陷入重复返回分心页的循环。
7. 暂停、结束、锁屏时不接收新的标签活动；恢复后按新的防抖周期判定。关闭桌面程序后扩展安静退回离线，不跳转页面。
8. 重启浏览器、扩展 worker 休眠后恢复，事件和 30 秒心跳应恢复连接。隐身/无痕、chrome://、edge:// 和 file:// 页面不采集。
9. 在扩展选项点“断开”，不再发送活动；重新配对可恢复。不同程序目录同时启动，第二个端口冲突只影响扩展，不影响本地规则会话。
