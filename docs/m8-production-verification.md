## 手动验收

1. 双击 `Start.cmd`，应打开浅色「今天学什么」页面且未开始监控。输入目标、选择时长、严格度；右上角 `◐` 切换深色后输入应保留。
2. 点规则行的 `+`，选择应用、搜索、多选、手动添加和删除；原有 AI 生成按钮、设置入口仍可使用。
3. 开始自己的测试会话，拖动悬浮窗到屏幕底部并展开，按钮应完整可见。从主窗口或托盘选择「悬浮窗」后，按 Tab 应可进入暂停按钮，继续访问休息、结束、返回主窗口和收起按钮。展开区应能看到 AI 状态。
4. 浮窗两分钟无交互后淡出，移入鼠标恢复。关闭 Windows 动画后，背景光团和呼吸动画应停止。
5. 在可控的分心测试中核对：L1 在浮窗附近显示；L2 出现屏幕边缘柔光和浮窗倒计时；L3 覆盖每块屏幕，「回到学习」始终可用。锁定结束后才显示申诉和应急入口。需分别检查不同缩放比例和负坐标副屏。
6. 结束后查看专注率圆环、四张数字卡片、时间轴与来源；在设置里保存一项可恢复的修改，重开核对。
7. 将主窗口最小化、恢复、关闭再从托盘打开，检查布局和操作。严格退出等可选功能只在主动启用后验收。

## 实现边界

- 浅/深色选择仅在本次运行有效，未改动设置模型。
- 主窗口使用 Mica，浮窗/提醒/遮罩使用 Acrylic；原生材质受 Windows 版本、透明效果和高对比度设置影响。较旧系统采用实色底与弥散光回退，尚未在 Windows 10 实机验收。API 依据：[DWM 背景材质](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)、[WPF WindowChrome](https://learn.microsoft.com/en-us/dotnet/api/system.windows.shell.windowchrome)。
- 按项目隐私约束，遮罩使用系统材质模糊背后的画面，不截屏保存桌面。
- 本轮没有启动真实学习采集或调用用户 API；真实 API 与功能流程沿用前一版本，实际多屏交互仍需上述手动检查。
- 发布 ZIP 为无个人数据的干净包。本机便携版升级另行保留旧版目录，并将原有 `data` 复制到新版，个人数据不进入源码或压缩包。
